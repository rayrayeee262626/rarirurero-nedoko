- 小4わり算：3桁÷1桁／3桁÷2桁を分ける。横式であり、縦の筆算枠がある教材とは約束しない。

## 今回の改善

1. 単元ページは、20問・答えつきの完成済みプリントを設定欄より先に配置。DOMも同じ順にして、視覚順とキーボード操作順を一致させた。
2. PDF保存・印刷・同条件での再生成を同じパネルへ集約。問題数や答えの設定にはページ内リンクで進める。
3. 説明文を、単元ごとの桁数・余り・商の範囲と「横式・答えつき・無料」に絞った固有の内容へ整理。長い導入文の重複を減らした。
4. 新しい単元や個人情報入力、追加の追跡項目は増やしていない。

390×844の初期スマホ画面では、全10ページのPDF保存ボタンが画面内に収まった。ボタン下端は最大582px。初期作成済みのプリントは、そのボタンから直接保存できる。これはブラウザーによる導線確認であり、初めて使う人の30秒達成率を実測したものではない。
