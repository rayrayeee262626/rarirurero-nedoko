## 整理した内容

- 大きな宣伝見出し、装飾見本、特長カード、主操作より前の学年別一覧を外し、計算の種類→左右の桁数→問題数・答え→保存・印刷の1つのカードに集約。
- PDF保存・印刷・別の問題にするボタンは各1つ。見本は「プリントの見本を見る」を開いた場合だけ表示。
- 既存10ページは、トップ下部の閉じた「学年から探す」にまとめる。リンクは静的HTMLに残す。従来の学年の目安プリセットも同じ場所に残し、選択後は設定欄へ戻る。
- 単元ページも同じ簡素な操作画面を使用。固有の説明・注意点・問題例は下部の「この単元について・問題例」に整理。
- タイトル、説明文、canonical、所有権確認タグ、14 URLのサイトマップ、既存のアクセス解析・匿名イベントを維持。

## 機能の保護と検証

計算エンジン、QRデータ、PDF生成・印刷レイアウト処理、Web Analyticsローダー、匿名イベントのWorkerと設定、単元ごとの出題条件は変更していない。app.jsの変更はプリセットがないページへの対応、短い状態文、移動したプリセット選択後のスクロールだけ。

既存13テスト、850件の演算・単元条件、静的SEO・内部リンク・サイトマップの確認に加え、ブラウザーで以下を検証する。

- 全10単元×4画面幅、見本の開閉、再生成、答え切替、10件のPDF保存、最大問題数での印刷。
- トップの四則演算・混合、あまり3設定、10/20/30/50問、答えあり・なし、各演算のPDF保存・印刷、学年6プリセット、生成できない条件の通知。
- スマホ初期画面での操作位置、ボタンの重複なし、下部に閉じた学年導線、10ページへのリンク維持。
- 解析タグの二重設置なし、匿名イベントの種類と項目の維持、DNT/GPC関連の既存テスト。ブラウザーテストは外向き通信をモックして利用実績に加算しない。

比較と機能検証を済ませてから、従来の専用workflowでprint-ponへ公開する。
