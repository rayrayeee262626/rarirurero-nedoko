# 出力前にできあがりを確認する

トップと既存10単元を、設定→「プリントを確認」→問題／答えを表示→その下からPDF保存・印刷、の順に変更。

- 初期状態では出力ボタンを表示・有効化しない。確認ボタンは結果を表示するだけで、ダウンロードや印刷を行わない。
- 計算・桁数・問題数・あまり・答えの有無を変えると確認状態を解除し、再確認してから出力する。
- 答えの有無の切替や確認・保存そのものでは問題を作り直さない。確認した式と同じ問題をPDF・印刷に出す。
- 「別の問題にする」は新しい問題を作って、すぐ確認画面に表示する。自動出力しない。
- 計算エンジン、出題条件、PDF生成とA4印刷の形式、SEO、10ページ、既存の解析を維持。

スマホの設定画面はsettings.png、確認画面はpreview.png。確認時のダウンロード0件・印刷呼出0件と、出力ボタンが見本の後にあることを検証。

ブラウザーで10単元×4画面幅、初回の出力不可、確認後の出力、設定変更後の再確認、答え切替時の式の維持、見本と印刷する式の一致、保存時の再生成なしを確認。従来の四則演算・混合、余り3設定、全問題数、学年プリセット、PDF・印刷、匿名イベントとDNTの検証も継続する。
