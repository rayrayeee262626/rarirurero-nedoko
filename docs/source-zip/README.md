# らりるれろの寝床（CMS連携版）

サイト表示にはCloudflare Pagesへ、このZIP全体を再デプロイしてください。GitHubには `.pages.yml` がすでに設定されています。

- Pages CMSで **ブログ・残しておきたい話** に記事を追加し「公開する」をONにすると、公開サイトがGitHubの `content/posts` を読み込んで記事を表示します。ブログは「書いたもの」、その他は「残しておきたい話」に表示。
- **作ったもの・制作中** で作品を追加・更新できます。最初から表示する6件の作品は、同名のCMS記事を作成し「サイトに表示」をOFFにすると隠せます。名称の一致が必要です。
- X埋め込みは変更していません。
- サイトはGitHubの公開APIをブラウザから読み込みます。無料ですが、GitHubのアクセス制限や接続状況によって一覧が一時的に読み込めない場合があります。
- 管理画面の編集が公開サイトに反映するまで、少し時間がかかる場合があります。
- このZIPではGitHubへのソースコード反映やCloudflare更新は自動実行していません。

## リンク表示の修正

Pages CMSにコピペした記事で `"表示名" (https://...)` と保存されたリンク、Markdownリンク、URL単体をクリックできるリンクとして表示するよう修正しています。既存の記事を編集する必要はありません。
